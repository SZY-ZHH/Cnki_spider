# 知网(CNKI)学术文献爬虫 - 高级版

基于 DrissionPage 的知网文献批量爬取工具，支持关键词搜索、PDF下载、CSV统计、增量更新、断点续爬、按关键词分类存储。

## ⚠️ 免责声明

本工具仅供个人研究学习使用，请遵守知网服务条款和版权法规，合理使用。

---

## 环境依赖

### Python 版本

- Python 3.8+

### 必需依赖

```bash
pip install DrissionPage
```

### 可选依赖（验证码自动识别）

```bash
pip install ddddocr
```

> 未安装 ddddocr 时，遇到验证码会自动等待30秒超时跳过，不会崩溃。

### 浏览器要求

- 需要本机安装 Chrome 或 Edge 浏览器
- 程序会自动检测以下路径：
  - `C:\Program Files\Google\Chrome\Application\chrome.exe`
  - `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`

## 快速开始

```bash
# 1. 安装依赖

请输入查询类型(学术期刊=1 学位论文=2 会议=3 报纸=4): 1
请输入爬取数量: 50
...
```

## 配置参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `KEYWORDS` | 必填 | 搜索关键词，多个用英文逗号分隔 |
| `SEARCH_TYPE` | 1 | 文献类型：1=学术期刊 2=学位论文 3=会议 4=报纸 |
| `TARGET_COUNT` | 10 | 每个关键词爬取的文章数量 |
| `SEARCH_MODE` | keyword | 搜索模式：keyword/title/abstract/author/fulltext |
| `TIME_START` | 不限 | 开始年份，直接回车跳过 |
| `TIME_END` | 不限 | 结束年份，直接回车跳过 |
| `DOWNLOAD_PDF` | y | 是否下载PDF文件 |
| `OUTPUT_DIR` | 默认 | 输出根目录，默认在当前目录下创建`知网爬虫`文件夹 |
| `LOGIN_METHOD` | skip | 登录方式：cookie/password/skip |
| `MIN_DELAY` | 3 | 文章间最小请求间隔（秒），过快可能触发验证码 |
| `MAX_DELAY` | 6 | 文章间最大请求间隔（秒） |
| `MAX_RETRIES` | 10 | 失败最大重试次数 |
| `USE_PROXY` | n | 是否使用代理 |
| `INCREMENTAL_UPDATE` | y | 增量更新模式，跳过已爬取的文章 |
| `AUTO_SAVE_PROGRESS` | 15 | 每爬取N篇自动保存进度 |

## 单位IP用户使用指南

本爬虫已针对**单位/校园IP直连知网**的用户进行优化：

1. **无需登录**：默认 `skip` 登录方式，单位IP自动拥有下载权限
2. **不预判付费**：只要页面有下载按钮就点击尝试，不会因为页面有"付费"文字就跳过
3. **仅跳过真正的付费页面**：只有点击下载后确实跳转到 `bar.cnki.net/fee` 付费页面，才会跳过该文章
4. **弹窗自动处理**：下载过程中的 Alert 弹窗会自动关闭，不会卡住程序

## 核心功能

### 1. 按关键词分类存储

每个关键词创建独立文件夹，数据、进度、PDF完全隔离。增量更新和断点续爬按关键词分别生效。

### 2. 付费文章处理

- 点击下载后自动检测是否跳转到付费页面
- 使用 JS 拦截 `window.alert` 防止弹窗阻塞浏览器
- 使用 `click(by_js=True)` 非阻塞点击，避免线程卡死
- 多策略检测：URL检测 → 新标签页弹窗 → JS拦截消息 → 原生Alert

### 3. 滑块验证码自动识别

- 使用 ddddocr 识别缺口位置
- 模拟人类滑动轨迹（加速段 + 减速段 + 微调）
- 最多自动重试3次
- 失败后自动等待30秒超时跳过

### 4. 增量更新 & 断点续爬

- 启动时从 CSV 和已下载文件加载去重集合
- 每篇文章成功后立即更新去重集合
- 自动保存进度，Ctrl+C中断后可恢复

### 5. CSV统计总结

- 每个关键词生成 `_data.csv`（完整元数据）和 `_总结.csv`（精简+下载状态）
- 总结CSV包含PDF下载状态关联检查

## 常见问题排查

### 1. 浏览器启动失败

**症状**：`浏览器初始化失败`

**解决**：
- 确认已安装 Chrome 或 Edge 浏览器
- 检查浏览器路径是否在默认安装位置
- 如使用自定义路径，修改代码中 `browser_paths` 列表

### 2. 搜索失败 / 找不到搜索框

**症状**：`未找到搜索框` 或 `搜索失败`

**解决**：
- 检查网络连接
- 知网页面可能改版，尝试更新 DrissionPage：`pip install --upgrade DrissionPage`
- 程序会自动尝试备用搜索方式

### 3. 下载卡住 / Alert弹窗阻塞

**症状**：程序长时间无响应

**解决**：
- 已通过 JS 拦截 + 非阻塞点击解决此问题
- 如仍卡住，按 Ctrl+C 中断，进度会自动保存

### 4. 验证码无法通过

**症状**：`自动滑块失败`

**解决**：
- 安装 ddddocr：`pip install ddddocr`
- 如果自动识别失败，程序会等待30秒，期间可手动完成验证
- 确保浏览器窗口可见（不要最小化）

### 5. 下载的PDF文件找不到

**症状**：日志显示下载成功但文件不在目录中

**解决**：
- 检查输出目录是否正确
- 浏览器可能弹出下载确认，检查浏览器下载设置
- 确认磁盘空间充足

### 6. 重复爬取

**症状**：已爬取的文章被重新处理

**解决**：
- 确保开启增量更新模式（默认开启）
- 不要手动删除 `_cnki_progress.json` 进度文件
- 检查 CSV 文件是否完整

## 技术架构

| 组件 | 技术 | 说明 |
|---|---|---|
| 浏览器自动化 | DrissionPage | 基于 Chrome DevTools Protocol，无需 WebDriver |
| 验证码识别 | ddddocr | 滑块缺口位置识别 |
| 弹窗拦截 | JS注入 | 覆盖 `window.alert`/`confirm` 防止阻塞 |
| 非阻塞点击 | `click(by_js=True)` | 避免 Alert 弹窗导致线程死锁 |
| 数据存储 | CSV + JSON | 元数据CSV + 进度JSON |
